# AJ5X Toolkit

**Lightweight Proxy Management & Testing Toolkit**

AJ5X Toolkit is a lightweight desktop application designed to manage, test, and operate proxy connections through a clean graphical interface.

It provides local SOCKS5 and HTTP proxy servers, upstream proxy chaining, asynchronous proxy testing, and live proxy management — all in one place.

## Features

- **Local Proxy Servers** — Run local SOCKS5 and HTTP proxy servers.
- **Upstream / Proxy Chaining** — Route connections through upstream proxies.
- **Optional Authentication** — Configure authentication for supported proxy connections.
- **Async Proxy Checker** — Test multiple proxies asynchronously.
- **Fast Mode** — Quickly scan proxy lists with optimized checking.
- **File Import** — Load proxy lists directly from external files.
- **Live Proxy Export** — Export only successfully verified proxies.
- **Copy Live Proxies** — Quickly copy working proxies to the clipboard.
- **Scan Statistics** — Monitor Alive, Average Response Time, and Best Response Time.

## Overview

AJ5X Toolkit brings proxy testing and local proxy management into a single desktop environment.

Instead of manually checking proxy endpoints or switching between multiple tools, users can import proxy lists, verify their availability, filter working proxies, and use upstream connections through locally hosted proxy servers.

## Use Cases

- Proxy availability testing
- Network diagnostics and experimentation
- Upstream proxy configuration
- SOCKS5 and HTTP proxy management
- Personal networking projects
