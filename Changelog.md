# Changelog

All notable changes to AJ5X Toolkit will be documented in this file.

## [0.0.1] - 2026-11-19

### Added
- Initial release of AJ5X Toolkit.
- Local SOCKS5 proxy server.
- Local HTTP proxy server.
- Upstream proxy and proxy chaining support.
- Optional proxy authentication.
- Asynchronous proxy checker.
- Fast Mode for proxy testing.
- Proxy list import from external files.
- Export only successfully verified proxies.
- Copy live proxies to clipboard.
- Scan statistics:
  - Alive proxies
  - Average response time
  - Best response time
- Graphical user interface.

### Notes
- First public release.
- Future updates may introduce additional features, improvements, and bug fixes.
